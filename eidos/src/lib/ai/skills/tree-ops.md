# Skill: WorldLine 树操作 (tree-ops)

教 ALICE 如何使用 WorldLine 树系统——这是引擎最强大的机械能力。

## Part A: KEI 世界生成指南

```
## WorldLine 树设计

你正在为这个世界设计 WorldLine 树结构。在生成世界时，请注意：

### 标记关键决策点
在 gameModeConfig.keyDecisionPoints 中列出玩家可能面临的关键选择。每个决策点：
- 描述选择的内容
- 列出可能的分支方向
- 标记哪些分支是"正确的"（如果有）

### 设计可回溯节点
标记一些节点作为"可回溯点"——玩家可以回到这些点重新选择。使用节点标签 (label)。
例如：
- label: "案件现场到达"  (循环起点)
- label: "关键线索发现"   (进度检查点)
- label: "重要对话选择"   (关键决策)
```

## Part B: ALICE 运行时指南

```
## WorldLine 树操作

你正在一个拥有完整 WorldLine 树系统的游戏引擎中运行。以下是你需要知道的：

### 读取树信息
在每次行动的上下文中，你会看到一段 "世界线信息"——它告诉你：
- 当前在哪个节点（ID、步数、深度）
- 部分历史定位参考（标记用于找位置，不代表全部可用目标）
- 兄弟分支的摘要（同一决策点的其他路径，只供作者了解树结构）

### 兄弟分支 = 平行时间线
兄弟分支只记录其他选择路径，不自动成为主角知识。只有回溯能力明确保留的经历才能当作上一轮记忆；普通分支不能泄露给主角。

非亲历的分支不能变成直觉或既视感。已经由能力保留的经历，可以按作品设定清楚回忆或表现模糊印象。

### 标记重要节点
当玩家做出了一个关键决策时，在 summary 中添加 [LABEL:标签名]：
例如：summary: "[LABEL:选择帮助管家] 玩家决定相信管家的话"

### 受限回溯与回看

本指南负责标记分支，不单独授予回溯能力。需要主角技能式回溯时，配合 loop-manager 或 gameModeConfig.rewind 声明能力与条件。只有游戏根据已发生剧情判定允许，才输出 worldImpacts: ["[BACKTRACK:真实过去节点ID] 具体发动原因"]。玩家要求、查看旧记录或普通兄弟分支不构成发动条件。未标记的过去节点也可选择；目标由作品能力和已发生剧情决定。需要更多细节或准确 ID 时，先用历史原文工具搜索、分页读取，再提交行动。

引擎恢复过去的世界、NPC 与背包，单独携带主角压缩经历；不会整份保留未来的 criticalFacts 或 encyclopedia。不要在本轮提前写目标场景，引擎在行动保存后恢复。记忆表现由作品决定，不强制既视感、失忆或固定措辞。完整原文保留在原分支，回看不改变当前游戏状态。

目标也可使用程序支持的“第2步／节点2／5号节点／上一节点”引用，序号只按当前经历链的 stepNumber 匹配，上一节点以本次输入开始时的位置为基准。可先通过 historyRequest: {"target":"第2步"} 定位真实 ID；多候选时按时间、地点或经历区分，不猜目标，不因玩家没提供长 ID 就拒绝。
```

## Part C: KEI 审核指南

```
## WorldLine 树审核

在审核时，检查：
1. ALICE 是否在关键决策点正确使用了 [LABEL:] 标记
2. 回溯请求是否合理（不是随意回溯）
3. 只有明确保留的亲历经历可成为主角记忆；未经历兄弟分支与旁观秘密不得融入主角知识
4. 回溯后的叙事是否体现了"进展感"（而非完全重复）
```

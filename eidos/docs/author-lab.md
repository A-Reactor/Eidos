# 作者实验室

作者实验室可以离线重放模组界面、玩法提交、存档和回溯。想先体验现成样例，可在 `eidos` 目录运行 `npm run dev:author`，打开 [作者实验室](http://127.0.0.1:4197/)，再从「源码模组」选择 `last-post`。实验室会记录需要模型处理的请求，实际叙事质量可在正式游戏里验证。

## 保存与重放

1. 游戏中打开“设置 → 作者工具 → 导出复现场景”。等待当前正文和本地保存完成。文件包含实际采用的世界／模组包、当前快照和正文，不包含模型连接设置、密钥、原卡原件或工作区媒体原件。它仍可能包含隐藏设定，分享前自行确认内容。
2. 在项目 eidos 目录运行 `npm run dev:author`，打开 `http://127.0.0.1:4197/`。该端口与正常游戏的浏览器存储分开；每次载入又创建独立沙箱周目，不覆盖正常游戏。
3. 拖入或选择 `scene.eidos-repro.json`。原来的对话、模组进度和包版本被带到新实验根节点；原世界的全部历史分支不包含在这个单现场文件中。需要全历史请使用现有世界备份／世界线导出。
4. 命名并保存检查点，在同一会话里反复恢复、操作或回溯。也可导出当前现场，下次打开时再导入。内存检查点列表不跨刷新保留。
5. “读取当前进度”把正在运行的模组状态填入编辑器。编辑后“应用实验状态”可直接跳到案件或章节的相应状态；无效 JSON／账本整批拒绝。这里是作者实验，允许构造不代表正常游玩的状态，不会送入原游戏。

读写现场期间如果继续操作，迟到的导入／导出会拒绝，避免混用不同状态。实验结果已接受但本地写入失败时，页面显示“重试保存”；它只重试写入，不重复决定、扣款或生成。完成保存前，切换现场和后续操作暂停。

现场文件与插件包不设人为字数或文件大小上限，仍校验格式与内容结构。当前现场导出以已保存正文 CAS 为准，不用可能滞后的阅读导航副本。原件缺失时明确报错。当前场景须存在于世界定义中；仅临时出现在百科的动态地点暂不支持现场文件，请先用完整世界备份。

## 改代码、看结果

选择“源码模组”里的目录。它把作者目录按实际打包逻辑装配，之后改 manifest、内容 JSON、HTML 或逻辑文件都会重载。为兼容不同文件系统，开发服务每 500 ms 轮询文件变化。

重载保留兼容的最新作者进度与正文，创建新的实验根节点；已有命名检查点仍可恢复此前的包和状态。它不是正式世界的包升级，不能用来替代迁移测试。重载不兼容状态时保留原现场并报错，可恢复检查点或编辑状态后再试。导入分享包可使用“替换实验模组”。真正分享仍运行 `node scripts/pack-mods.mjs <目录>`。

AI 续写／自由行动在右侧列出最近 50 个待处理请求。材料分析、原生窗口和桌面文件通道被拒绝；iframe 网络资源受离线策略限制。普通工作区虚拟文件及嵌入纸窗可继续测试；原件没有包含在现场文件中，使用这些功能时需另行导入。此实验室只在本地开发服务中提供，不增加游戏主界面入口或线上执行接口。

## 混合叙事样本

选择源码 `last-post`，或导入[最后一班邮车](../mods/dist/last-post.eidos-plugin.json)。走进邮局、读信、寄出或暂留都能离线完成；“请 AI 写现场反应”和任意自由行动只在实验室记录请求。正式游玩会使用玩家自己的模型配置。

作者改 `mods/last-post/story.json` 的内容、`logic.js` 的判断或 `index.html` 的显示。作者片段直接保存进世界线；模型按正式 facts 承接，不能因续写失败重复本地结算。玩家没有被要求每次都按预写路线行进。

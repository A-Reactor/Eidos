# 剧情锚定点

创建世界时，在现有玩法列表选择「剧情锚定点」，再把希望反复出现的关键结果写进特殊设定或世界概念。它只增加创建、叙事和审核的提示词，沿用原有主界面、人物、线索、时间、存档和世界线功能，不需要额外操作。

模型会在合适的场面，依据仍然存在的世界原因，让不同路径趋向同一关键结果。日常、探索和支线仍可正常展开；某次行动成功，成果应当保留。改变持续成因后，结果也可以改变。它不是对每次操作的强制判定，不能保证模型绝不偏离设定。

## 怎样写特殊设定

写清结果、成立前提和可供发现的原因即可。突破方式可以留给模型与玩家共同探索，也可以由作者预先设计；不需要列程序条件或为每条分支写剧本。以下示例互相独立，选择适合本作的一种改写即可。

**人物关系**：只要两人还在各自隐瞒家庭债务，不同旅行路线最终都会让他们在入冬前分开。相处与局部帮助可以真实改善关系；共同了解困境并找到可持续的安排后，分别才可能被避免。用信件、回避话题和生活压力逐渐显露原因，不直接告诉玩家结论。

**政治与调查**：只要关键证据仍被同一利益集团垄断，无论谁先提出指控，听证最终都会形成替罪者。玩家可以救下具体证人、保存证物、改变舆论；若这些行动真正打破证据垄断，听证也可以走向另一结果，不指定唯一解法。

**日常与经营**：只要旧水渠的污染源未被处理，不同种植、交易和社交安排最终都要面对秋季停灌。经营成果和人情关系仍有效，也会改变损失与援助；污染成因解决后，不再强行安排另一场灾害来保持停灌。

**悲剧与循环**：在威胁某人的持续原因尚未解除时，单次躲避和换路线会延缓危险，但不同经历仍趋向失去此人。玩家逐渐发现不变因素，有依据的新方案可以真正破局。是否回溯、如何发动和带回什么记忆，交给另外的「循环与受限回溯」插件及世界设定，不由锚点插件自动开启。

也可明确写“此篇中的某个结果始终不可避免，但经历、关系和代价可以改变”，用于悲剧或主题叙事。不要把每个小事件都设为锚点，否则很容易挤掉玩家选择的空间。

## 沿用现有资源

- 创建模型将锚点整理到自由格式的 `gameModeConfig.storyAnchors`，随世界保存及导出。该配置描述设计，不是自动执行或自动更新的条件账本。
- 线索和人物反应帮助玩家辨别表面路径与持续成因；当前进度以已接受的经历、事实及世界状态为准。
- 时间要求沿用游戏时间和预设事件，不新增固定行动次数。已经声明定时事件时，结合事件的实际进展理解锚点，不把全部事件变成不可干预。
- 普通分支和回溯沿用现有世界线；锚点不是回溯位置，也不增加跨分支记忆权限。没有循环能力的世界同样适用。
- 审核关注因果、节奏和行动成果，不因普通回合没有推进锚点而要求重写，也不追加每回合的专门审查。

# 阅读交互开发入口

在 eidos 目录执行 `npm run test:reading`，集中验证段落回看、节点预生成、行动拒绝和时间推进。成功时只输出简短结果，不需要浏览器逐项操作。

需要检查视觉效果时执行 `npm run dev:game`，打开 `http://127.0.0.1:3020/`。复用正式 GameScreen，固定世界与网络响应，独立端口隔离本地存储。

- `/?case=reading`：阅读中的正文和已有分支，检查聚焦、菜单与父子节点切换。
- `/?case=invalid`：预填不合理行动，点击发送检查临时反馈，再点“返回原节点”。
- `/?case=rest`：预填“歇息到傍晚”，发送后时间从 14:30 到 18:30。
- `/?case=npc`：人物档案、证词来源回看和玩家备注。也可返回游戏，从世界状态的“人物档案”进入。

右上“当前世界 AI 用量”、输入左侧“播放与快捷设置”、记录的“上一行动记录”和“下一行动记录”均有明确的可访问标签。优先按标签操作；需要检查状态时读取对应控件一次，不必反复截取整页。视觉检查结束后运行全量测试和构建即可。

此入口位于 dev 目录，不进入 Next.js 生产路由。网络请求被替换为固定响应，不读取或使用真实服务凭据。

- `/?case=worldline&theme=light`：同一路径连续分叉、兄弟分支日期不同的 356 节点世界线，用来检查左右分配、子树位置、展开与标尺对应。
- `/mobile.html`：390×844 iframe 手机布局验证，复用上述跨日分叉场景。

- `/mobile.html?case=library`：手机世界详情，含周目、手动存档和自动恢复点。
- `/mobile.html?case=map`：手机地图目录、地点详情与分层返回。

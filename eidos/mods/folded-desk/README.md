# 文件交互与跨分支解谜

主动打开文件工具后编写信件、向同周目的其他分支寄送与收取，操作纸窗和局部规则解谜，也可递交材料请求分析。

## 导入与使用

在创建世界的玩法区域导入 `mods/dist/folded-desk.eidos-plugin.json` 并选中。已有世界可在设置中打开对应模组的版本更新，选择新包并预览后应用；磁盘上的文件更新不会自动替换存档内的安装包。

- 在设置 → 作者工具 → 插件工作台与交互工具中明确打开本工具；普通游玩时不自动显示。
- 编写并保存信件，在同一周目明确寄出，再到另一分支主动收取。
- 操作纸窗拼合两岸、修改局部通行规则，或使用示例中的记忆交换解谜；这些是工具所定义的局部故事状态。
- 可递交文件原件；只有主动请求材料分析才调用已配置的模型并计入用量。关闭工具后回到原游戏界面。

## 作者与示例

使用 `npm run dev:author` 可加载源码做离线调试；离线实验室不调用真实模型。

修改内容后运行 `node scripts/pack-mods.mjs folded-desk` 重新生成分享包。

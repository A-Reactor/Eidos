# 证据对照与群体辩论

逐条核对人物发言，调查并出示证据，选择反驳或支持。证据与发言的关系按案件事实核验，过程融入原有正文和行动。

## 导入与使用

在创建世界的玩法区域导入 `mods/dist/debate-room.eidos-plugin.json` 并选中。已有世界可在设置中打开对应模组的版本更新，选择新包并预览后应用；磁盘上的文件更新不会自动替换存档内的安装包。

- 开始调查并阅读当前人物的发言，通过推荐行动调查记录。
- 针对当前发言选择一份已取得的证据，并明确反驳或支持。
- 证据和方向均符合案件事实才推进；选错后仍可换材料或方向重试。
- 可暂离、恢复案件，或在原输入框自由行动；发言和结果都保留在原有行动记录中。

## 作者与示例

默认游玩使用原有正文、行动记录、推荐行动和输入框。作者工作台需在设置 → 作者工具中主动展开，不会常驻主界面。

使用 `npm run dev:author` 可加载源码做离线调试；离线实验室不调用真实模型。

修改内容后运行 `node scripts/pack-mods.mjs debate-room` 重新生成分享包。

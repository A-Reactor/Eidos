# 人物心智与承诺互动

让当前世界的角色依据各自见闻、欲望和经历回应你，在交谈与行动中表现误解、核验、承诺、履约和自主合作。

## 导入与使用

在创建世界的玩法区域导入 `mods/dist/social-minds.eidos-plugin.json` 并选中。已有世界可在设置中打开对应模组的版本更新，选择新包并预览后应用；磁盘上的文件更新不会自动替换存档内的安装包。

- 直接与当前世界的角色交谈、私聊、传达消息或一起行动，使用原有输入与推荐行动。
- 人物应依据自己的信息来源、欲望、压力和过往经历回应，允许误解、核验、拒绝和有条件合作。
- 明确承诺的对象、内容和期限，再由实际行动体现履约或失约及其后果。
- 默认玩法由 AI 结合现有人物记忆、人格和关系生成互动；旧版三人车站会谈及十回合结算样例仅保留在作者工作台。

## 作者与示例

默认游玩使用原有正文、行动记录、推荐行动和输入框。作者工作台需在设置 → 作者工具中主动展开，不会常驻主界面。

使用 `npm run dev:author` 可加载源码做离线调试；离线实验室不调用真实模型。

修改内容后运行 `node scripts/pack-mods.mjs social-minds` 重新生成分享包。

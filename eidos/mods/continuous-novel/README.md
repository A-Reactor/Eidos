# 连续阅读与剧情选择

沿用原有阅读界面推进小说、章节与配角视角，在重要时刻作出选择，也可随时自由输入行动。

## 导入与使用

在创建世界的玩法区域导入 `mods/dist/continuous-novel.eidos-plugin.json` 并选中。已有世界可在设置中打开对应模组的版本更新，选择新包并预览后应用；磁盘上的文件更新不会自动替换存档内的安装包。

- 沿用原游戏的逐段阅读、回顾和自动阅读控制。正文结束后，可从推荐行动选择“继续故事”。
- 有明确的关键选择时，选择对应行动；也可在输入框自由表达自己的做法。
- 配角镜头中的选择属于该角色；“回到主角”会接回主角处境，旁观内容不会自动成为主角知识。
- “普通剧情自动续写”需在插件设置中主动开启；原版自动阅读暂停、关键选择、章末和结尾都会阻止自动续写。续写会调用模型并计入用量。

## 作者与示例

默认游玩使用原有正文、行动记录、推荐行动和输入框。作者工作台需在设置 → 作者工具中主动展开，不会常驻主界面。

使用 `npm run dev:author` 可加载源码做离线调试；离线实验室不调用真实模型。

修改内容后运行 `node scripts/pack-mods.mjs continuous-novel` 重新生成分享包。

变体 `night-voyage-short.eidos-plugin.json` 是以旧港夜车和迟到的信为素材的三章示例，提供配角决定和返回主角的情境，允许自由行动偏离示例路线。

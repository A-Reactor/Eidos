# 逐句追问与证据质询

逐句听取和追问证词，再用已取得的证据核对补充后的陈述。错误尝试可重试，确认的结果随存档和分支保留。

## 导入与使用

在创建世界的玩法区域导入 `mods/dist/cross-examination.eidos-plugin.json` 并选中。已有世界可在设置中打开对应模组的版本更新，选择新包并预览后应用；磁盘上的文件更新不会自动替换存档内的安装包。

- 从推荐行动开始或继续当前案件，证词直接出现在原有正文里。
- 调查取得记录，逐句追问，读清补充后的证词，再选择出示哪一份证据。
- 未取得的证据不能用于核对；错误尝试停在当前句，可以换证据重试。
- 可以暂离调查，继续自由行动，再恢复案件。站台时钟和雾港剧情触发版使用相同操作。

## 作者与示例

默认游玩使用原有正文、行动记录、推荐行动和输入框。作者工作台需在设置 → 作者工具中主动展开，不会常驻主界面。

使用 `npm run dev:author` 可加载源码做离线调试；离线实验室不调用真实模型。

修改内容后运行 `node scripts/pack-mods.mjs cross-examination` 重新生成分享包。

变体 `station-cross-examination.eidos-plugin.json` 使用站台时钟案件；`harbor-hearing.eidos-plugin.json` 按剧情进入或离开雾港质询。它们沿用相同的原有阅读与行动界面。

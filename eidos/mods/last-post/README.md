# 预写剧情与 AI 即兴

阅读作者写定的信件与对白，选择代寄或暂留；也可自由调查和行动，由 AI 承接人物反应。正文、决定和回溯使用原游戏流程。

## 导入与使用

在创建世界的玩法区域导入 `mods/dist/last-post.eidos-plugin.json` 并选中。已有世界可在设置中打开对应模组的版本更新，选择新包并预览后应用；磁盘上的文件更新不会自动替换存档内的安装包。

- 从推荐行动走进旧港邮局，阅读作者预写的信件与对白。
- 选择阅读柜台上的原信、请白槿代寄，或暂时保留。寄出与暂留是互斥的局部决定。
- 可自由调查、交谈或离开，由 AI 承接当前世界及已确认的决定。
- 作者原文和分支决定随存档保存；回溯后可以探索另一个选择。

## 作者与示例

默认游玩使用原有正文、行动记录、推荐行动和输入框。作者工作台需在设置 → 作者工具中主动展开，不会常驻主界面。

使用 `npm run dev:author` 可加载源码做离线调试；离线实验室不调用真实模型。

修改内容后运行 `node scripts/pack-mods.mjs last-post` 重新生成分享包。

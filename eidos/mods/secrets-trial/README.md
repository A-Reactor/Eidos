# 人物调查与秘密审判

从人物日常和能力限制入手调查，收集物证、核对证词，在证据链成立后提出指控，并决定保护私信或明确公开原文。

## 导入与使用

在创建世界的玩法区域导入 `mods/dist/secrets-trial.eidos-plugin.json` 并选中。已有世界可在设置中打开对应模组的版本更新，选择新包并预览后应用；磁盘上的文件更新不会自动替换存档内的安装包。

- 开始案件，或直接调查可见地点；与人物谈日常和能力，听取证词。
- 通过原有推荐行动或自由输入调查物证，再选择证物核对具体证词。
- 案件规则同时核验所需物证和证词矛盾；证据链不足不能确认有罪，错误指控不结案。
- 证据链成立并确认指控后，决定只提交匿名事实保护私信，或明确公开原文。

## 作者与示例

默认游玩使用原有正文、行动记录、推荐行动和输入框。作者工作台需在设置 → 作者工具中主动展开，不会常驻主界面。

使用 `npm run dev:author` 可加载源码做离线调试；离线实验室不调用真实模型。

修改内容后运行 `node scripts/pack-mods.mjs secrets-trial` 重新生成分享包。
